## Осознанные решения
- **m1:** файл экрана `src/screens/auth/ConfigURLScreen.tsx` и константа `CONFIG_URL: 'ConfigureURL'` (`src/constants/index.ts`) оставлены в дереве, но экран не зарегистрирован ни в одном навигаторе (мёртвый код) — чтобы апстрим-апгрейды давали минимальный конфликт; на UI экран недостижим.
- **m3:** пакет `@sentry/react-native` оставлен в `package.json` и в `metro.config.js` (`getSentryExpoConfig`) — native-модули Sentry остаются слинкованными (в logcat видны безобидные регистрационные варнинги `ViewManagerPropertyUpdater: Could not find generated setter for io.sentry.react.*` и `io.sentry.auto-init read: false`), но без `Sentry.init`/DSN исходящей телеметрии нет; `Sentry.captureException` по коду (`settingsActions.ts`, `errorUtils.ts`, `permissionUtils.ts`, `AppTabs.tsx` и др.) = no-op. Выпил пакета/вызовов дал бы большой дифф против апстрима — сознательно не делаем. `analyticsUtils.ts` НЕ менялся: конструктор уже гейтит June по наличию ключа, ключ убран из env — SDK не зовётся.
- **m2:** `src/svg-icons/common/Chatwoot.tsx` (`ChatwootIcon`) НЕ удалён — ещё используется как generic-фолбэк канала в `src/utils/getChannelIcon.tsx` (не видимый брендинг); замена коснулась только Settings. `selectIsChatwootCloud` сохранён как селектор (возвращает `false`) — сигнатуру не меняем, чтобы апстрим-диффы шли чисто. `google-services.json` (gitignored, заглушка Task 7) при смене package id надо перевести на `ru.conomni.app` вручную — иначе `processDebugGoogleServices` падает «No matching client»; реальный Firebase-конфиг заведёт Task 7.
- **m4 (concerns для Павла, НЕ фиксили):** (1) системные Android-диалоги («Allow ConOmni to send you notifications?», нативный «Select action» chooser у пункта «Conversation Actions» в шапке чата — это intent chooser ОС, не связан с панелью действий диалога) идут на языке ОС, а не приложения — вне досягаемости JS i18n, точечный фикс не нужен пока ОС на английском у тестового эмулятора. (2) `LOGIN.EMAIL_REQUIRED`/`EMAIL_ERROR` содержат англ. заимствование «Email» («Необходимо указать Email», «Введите правильный email») — существующий текст до m4, вне списка спайка Task 2, не трогали (не смешивать с доводкой 45 ключей). (3) широкого рефакторинга НЕ делали — все фиксы точечные (замена хардкод-строки на `i18n.t(...)` в 1 файле/1-3 местах каждый), как предписывает правило пропорциональности брифа.
- **Из финального whole-branch ревью (Fable, вердикт Ready-to-merge Yes, 0 Critical/Important):**
  (1) **МИНА для будущих ребейзов:** `SSO_CALLBACK_URL = 'chatwootapp://auth/saml'` (`src/constants/index.ts`) + `ssoUtils.ts` НЕ переведены на scheme `conomniapp` при m2 — сегодня мёртвый код (m1 делает `showSsoLogin` навсегда `false`), но если апстрим-апгрейд сменит SSO-гейт с проверки `app.chatwoot.com` на EE/серверную capability — SSO включится с scheme, который приложение больше не регистрирует. При включении SSO — сначала перевести литералы на `conomniapp://`. (2) `@chatwoot/react-native-widget` оставлен в `package.json` без потребителей (единственное использование убрано в m2) — по аналогии с Sentry оставлен ради малого диффа; при желании можно дропнуть (self-contained). (3) сток-мистранслейшны ru вне спайк-скоупа остались (`FILTER.ALL_INBOXES`=«Все письма» → надо «Все входящие»; `UN_ASSIGN`=«Отменить беседу» → значит cancel, не unassign) — тот же класс, что поправленный `NOTIFICATION.INBOX`, кандидаты на будущий polish-свип.
